ALIVE FASHION STUDIO — FREE WEBSITE
===================================

Files
- index.html      Website pages/sections and content
- styles.css      Responsive styling for phones, tablets and desktop
- script.js       Phone/WhatsApp settings and mobile navigation
- assets/logo.svg Custom vector logo

BEFORE PUBLISHING
1. Open script.js in a text editor.
2. Replace SITE_SETTINGS.phone and SITE_SETTINGS.whatsapp with your real phone/WhatsApp number, digits only, including country code 91. Do not leave the sample number.
3. Replace SITE_SETTINGS.city with your actual city/address.
4. Optionally add business email and social profile URLs.
5. Review all website text and contact details.
6. Add your own clothing photos later. The collection cards currently use designed placeholders.

TEST LOCALLY
- Keep all files in the same folder.
- Open index.html in a browser. For best results, use a local server such as VS Code Live Server.

PUBLISH FREE WITH CLOUDFLARE PAGES (DIRECT UPLOAD)
1. Create/sign in to a Cloudflare account: https://dash.cloudflare.com/
2. In the dashboard, open Workers & Pages (or Compute/Workers & Pages, depending on the current UI).
3. Choose Create application / Create, then Pages, and look for Direct Upload or upload assets.
4. Upload the website folder or a ZIP containing index.html at the root, plus styles.css, script.js and assets/logo.svg.
5. Choose a project name such as alive-fashion-studio. Follow the prompts to deploy.
6. Cloudflare will provide a free pages.dev URL. Open it on your phone and test every navigation and contact link.

If the dashboard only offers a Git integration flow, create a GitHub repository, upload these files with index.html at the repository root, then select that repository in Cloudflare Pages. Use the framework preset “None” and set the build command blank (or no build command) and output directory to the root directory, usually /.

IMPORTANT
- Cloudflare's interface and plan limits can change; follow the options currently shown in your account.
- A free pages.dev URL does not mean you own a custom .com domain. A custom domain usually costs money.
- Do not use false company details to apply to any startup program. A website alone does not guarantee eligibility or acceptance into Anthropic's startup program.
